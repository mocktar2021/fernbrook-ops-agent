> **Note:** these policy documents belong to the original manual setup, where a human IAM user ran CLI commands. The CI/CD roles that replace that are defined in Terraform in `infrastructure/bootstrap/`. This folder is kept as reference for how permissions were scoped.

# IAM policy: grows one design note at a time

`fernbrook-agent-builder-policy.json` is the policy attached to the IAM identity you use throughout this project. It starts small on purpose: as of Design Note 4 it grants nothing except the ability to view and configure cost budgets, read Cost Explorer data, and check its own IAM identity. No Bedrock access. No AgentCore access. No permission to create compute, storage, or networking resources of any kind.

Every later design note that needs a new AWS capability adds exactly the statements that capability requires, and says so explicitly, instead of the project granting broad access up front and asking you to trust that it'll be narrowed later. That narrowing almost never happens in real projects once broad access is already working. This repository doesn't model that habit.
